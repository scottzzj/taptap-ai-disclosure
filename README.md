| 环节 | 是否使用 AI | 具体用法 | 人工处理 |

## 四、生成方式与可追溯性

- 代码与文案：AI 编程助手（WorkBuddy）在本地项目中生成，全部变更进入 Git 版本库，可按提交追溯。
- 图像：使用 TapTap 制造内置图像生成与 WorkBuddy 图像生成能力出图，产物存放在项目 `assets/image/` 目录，配套 `.meta` 资源元数据。
- 音频：生成脚本为 `tools/gen_bgm_battle.py`（纯 Python 标准库），可复现同一音轨；成品为 `assets/audio/courtyard-loop.ogg`（主）与同名 `.wav`（兜底）。

## 五、未使用 AI 的部分（澄清）

- 游戏截图：全部来自真实运行画面渲染，未使用 AI 生成或 AI 修图。

- 广告素材与商店物料中的文字排版：人工完成。
